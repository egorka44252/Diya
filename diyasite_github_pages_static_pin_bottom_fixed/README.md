# GitHub Pages static build

This build has no Telegram Mini App integration, no login, no backend, and no database.
Settings in **Menu → Налаштування** are stored locally in the browser (localStorage/IndexedDB).

## Publish
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and wait for the Pages URL.
